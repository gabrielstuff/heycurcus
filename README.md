# heycurcus.com

> CV Marketplace pour Étudiants — 100% gratuit pour les candidats

## Quick Start

```bash
# Install dependencies
bun install

# Development
bun run dev

# Build & Deploy
bun run deploy
```

## Stack

- Nuxt 4
- Cloudflare Workers
- D1 (database) — à venir
- R2 (storage) — à venir

## Deploy

```bash
bun run deploy
```

Ou manuellement :
```bash
bun run build
wrangler deploy
```
